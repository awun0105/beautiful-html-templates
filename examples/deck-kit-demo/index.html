Bayes, in one line

The posterior is $p(x \mid z) \propto p(z \mid x)\,p(x)$, and for Gaussians the fused variance is

$$\sigma^2 = \frac{\sigma_A^2\,\sigma_B^2}{\sigma_A^2 + \sigma_B^2}$$

Prices stay text: the sensor costs $5 and the kit $10, US$5-$6.

Maths is plain $…$ in the HTML; deck-kit renders it with KaTeX. The price sentence shows that dollar amounts stay text.

Code, line by line

def kalman_step(x, P, z, R):
    # predict
    x_pred, P_pred = x, P + Q
    K = P_pred / (P_pred + R)        # gain
    x_new = x_pred + K * (z - x_pred)
    return x_new, (1 - K) * P_pred
